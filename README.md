# ⚡ YT-DLP Ultimate Downloader

Интерактивный медиа-загрузчик для **macOS** и **Linux**.  
Позволяет в 1 клик скачивать видео и музыку с YouTube, VK, Rutube, TikTok, Twitter/X, SoundCloud и более 1000 сайтов.

---

## 🚀 Как запустить

1. Откройте **Терминал** и перейдите в папку:
   ```bash
   cd ~/Downloads/yt-downloader
   ```

2. Запустите скрипт:
   ```bash
   bash start.sh
   ```
   *(При первом запуске скрипт сам проверит и установит все зависимости: `yt-dlp`, `ffmpeg`, `fzf`)*.

3. После первой установки программу можно вызывать из любого места терминала просто словом:
   ```bash
   yt
   ```

## ✨ Возможности

- 🚀 **Быстрые пресеты в 1 клик**:
  - Максимальное качество (4K / 2K / 1080p 60fps) со звуком в MP4/MKV.
  - Мгновенный MP3 (~320 kbps) с обложкой и тегами.
  - Минимальный вес (для лекций и экономии трафика).
- ✂️ **Скачивание отрезков по времени (Time-slice)**:
  - Укажите интервал (например, `01:15-02:45`), чтобы скачать только нужный фрагмент без загрузки всего ролика.
- 🎯 **Выбор точного качества**:
  - 4K (2160p), 2K (1440p), 1080p, 720p, 480p, 360p + выбор контейнера (MP4, MKV, WebM).
- 🎵 **Форматы аудио**:
  - MP3, M4A/AAC, FLAC (lossless), WAV, OPUS, Direct Stream (без перекодирования).
- 📜 **Плейлисты и субтитры**:
  - Скачивание целых плейлистов или диапазона (например: `1-10`).
  - Скачивание субтитров (русские, английские, автосабы).
- 🍎 **Фишки для Mac**:
  - Автоподхват ссылки из буфера обмена (`Cmd+C` перед запуском).
  - Звук и уведомление по окончании загрузки.
  - Быстрое открытие папки с файлом в Finder.
