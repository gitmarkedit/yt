# ⚡ yt (macOS Edition)

[![Platform](https://img.shields.io/badge/Platform-macOS%20(Apple%20Silicon%20%2F%20Intel)-000000?style=for-the-badge&logo=apple&logoColor=white)](https://apple.com)
[![Bash](https://img.shields.io/badge/Shell-Bash%203.2%2B%20%2F%20Zsh-4EAA25?style=for-the-badge&logo=gnu-bash&logoColor=white)](https://www.gnu.org/software/bash/)
[![Engine](https://img.shields.io/badge/Engine-yt--dlp%20%2B%20ffmpeg-FF0000?style=for-the-badge&logo=youtube&logoColor=white)](https://github.com/yt-dlp/yt-dlp)
[![Acceleration](https://img.shields.io/badge/Hardware-VideoToolbox%20Accelerated-007AFF?style=for-the-badge&logo=apple&logoColor=white)](https://developer.apple.com/documentation/videotoolbox)

Интерактивный, надежный и стильный консольный медиа-загрузчик с аппаратным ускорением, TUI-меню, анимациями и пресетами качества.  
Проект спроектирован **преимущественно для macOS** с глубокой оптимизацией под процессоры Apple Silicon (M1/M2/M3/M4) и экосистему Mac (буфер обмена, QuickLook, Finder, уведомления и звуки), а также сохраняет совместимость с Linux.

Поддерживает загрузку с **YouTube, VK Видео, Rutube, TikTok, Twitter/X, Instagram, Vimeo, SoundCloud** и более чем 1000 других медиа-платформ.

---

## 🛠️ Зависимости (Dependencies)

Для полноценной работы загрузчика используются ключевые компоненты:

| Утилита | Статус | Зачем нужна в проекте | Установка |
| :--- | :--- | :--- | :--- |
| **`yt-dlp`** | **Обязательно** | Основной движок загрузки. Извлекает медиапотоки на максимальной скорости. | `brew install yt-dlp` |
| **`ffmpeg` + `ffprobe`** | **Обязательно** | Мультимедиа-комбайн. Склеивает 4K/1080p со звуком, кодирует MP3/M4A/FLAC, вшивает обложки и теги. Поддерживает Apple VideoToolbox. | `brew install ffmpeg` |
| **`fzf`** | *Опционально* | Интерактивное нечеткое TUI-меню со стрелочками и поиском. *(При отсутствии скрипт автоматически использует встроенное нумерованное меню)*. | `brew install fzf` |
| **`node`** / **`deno`** | *Рекомендуется* | Движок JavaScript для автоматического решения YouTube player challenge. | `brew install node` |

> 💡 **Автоматическая установка:** Скрипт `install.sh` сам проверяет и устанавливает все необходимые зависимости в 1 клик, настраивает пути окружения и системную команду `yt`.

## 🍎 Преимущества и особенности для macOS

- ⚡ **Аппаратное ускорение VideoToolbox**: использование аппаратного медиа-ядра процессоров Apple Silicon (M1/M2/M3/M4) для мгновенной сборки и мультиплексирования.
- 🚀 **QuickLook & FastStart (`-movflags +faststart`)**: метаданные `moov atom` перемещаются в начало файла, благодаря чему видео любого размера мгновенно открывается по нажатию **Пробела** в Finder.
- 🍏 **Apple Compatibility Mode**: принудительный приоритет нативных кодеков H.264/HEVC и AAC для 100% совместимости с QuickTime Player, iOS и AirPlay без черного экрана.
- 📋 **Интеграция с буфером обмена (`pbpaste`)**: скопируйте ссылку в браузере (`Cmd + C`) — скрипт мгновенно подхватит её при запуске.
- 🔔 **Системные уведомления и звуки**: по завершении загрузки воспроизводится системный сигнал (*Glass*) и отображается уведомление macOS.
- ⚡ **Многопоточность (`-N 8`)**: загрузка фрагментов в 8 параллельных потоков на Apple Silicon для полной утилизации гигабитного канала.
- 🩺 **Режим самодиагностики (`yt --doctor`)**: комплексный аудит Bash, VideoToolbox, yt-dlp, FFmpeg, прав доступа и дискового пространства с пошаговыми инструкциями решения любых проблем.

## 🚀 Быстрый старт (Установка в 1 команду)

### Вариант 1. Установка в 1 команду (Самый простой способ для любого Mac)
Установщик автоматически проанализирует вашу систему, проверит наличие **Homebrew** (и при необходимости предложит его установить), либо загрузит автономные бинарники с аппаратным ускорением **VideoToolbox** без необходимости ввода пароля root или установки тяжелого пакета Xcode (12+ ГБ).

Откройте программу **Терминал** (`Cmd + Пробел` -> введите `Терминал` -> `Enter`) и вставьте одну команду:
```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/gitmarkedit/yt/main/install.sh)"
```
*Установщик выполнит аудит зависимостей, настроит медиа-движок, пропишет системную команду `yt` и сразу откроет загрузчик!*

---

### Вариант 2. Автономная установка через архив
```bash
mkdir -p ~/yt && curl -fsSL https://github.com/gitmarkedit/yt/archive/refs/heads/main.tar.gz | tar -xz -C ~/yt --strip-components=1 && bash ~/yt/install.sh
```

---

### Вариант 3. Через Git (для разработчиков)
```bash
git clone https://github.com/gitmarkedit/yt.git ~/yt && cd ~/yt && bash install.sh
```

#### Флаги установщика `install.sh`:
- `--brew` — принудительно использовать Homebrew (установит Homebrew, если отсутствует)
- `--standalone` — быстрая автономная установка без Homebrew и без прав администратора
- `--no-launch` — не открывать приложение автоматически после завершения установки

---

### Как запускать программу в дальнейшем:
Из любой папки терминала:
```bash
yt
```
Или передав ссылку напрямую:
```bash
yt "https://www.youtube.com/watch?v=..."
```
*(Также всегда доступен локальный запуск через `bash start.sh` внутри папки `~/yt`).*

## 🩺 Диагностика окружения (`yt --doctor`)

Для комплексной проверки системы, проверки доступности аппаратного ускорения Apple VideoToolbox и самоотладки выполните:
```bash
yt --doctor
# или
yt --diag
```

Режим диагностики проверяет:
1. Версию Bash (поддерживается нативный macOS Bash 3.2+).
2. Архитектуру и модель CPU (Apple Silicon M-серии / Intel).
3. Бинарник и версию `yt-dlp`.
4. `ffmpeg` и наличие аппаратных энкодеров `videotoolbox` (`h264_videotoolbox`, `hevc_videotoolbox`).
5. Наличие селектора `fzf` и движка `node`.
6. Права на запись и свободное место в целевой папке.
7. Синтаксис и целостность конфигурационного файла.

## 🎛️ Меню и возможности

- 🚀 **Максимальное качество (Best Video + Audio)** — скачивает наилучшее доступное качество (до 4K/8K 60fps) и объединяет в MP4/MKV.
- 🎵 **Сразу MP3 (320 kbps)** — извлечение звука с обложкой и тегами в один клик.
- 🪶 **Минимальный вес (Эконом)** — быстрый просмотр с экономией трафика и места.
- 🎯 **Выбор разрешения** — ручной выбор: 2160p (4K), 1440p (2K), 1080p, 720p, 480p, 360p.
- 🎧 **Другие аудиоформаты** — M4A (нативный Apple без потерь), FLAC (Lossless), WAV, OPUS, Direct Stream.
- ✂️ **Скачивание фрагмента (Time-slice)** — загрузка только нужного таймкода (например: `01:15-02:45`).
- 📜 **Плейлисты** — загрузка всего плейлиста или диапазона номеров (`1-10`).
- 📋 **Список форматов (`yt-dlp -F`)** — просмотр всех дорожек и выбор по ID.
- 💬 **Субтитры** — загрузка субтитров на русском, английском или всех доступных языках.
- 🖼️ **Только обложка** — сохранение постера в оригинальном разрешении.
- ⚙️ **Настройки** — смена папки (`~/Downloads/Media`), числа потоков, куков браузера (Safari/Chrome/Firefox).

## ⚙️ Конфигурация

Конфигурационный файл хранится по адресу:  
`~/.config/yt-downloader/config.env`

Файл автоматически создается и валидируется, защищен от повреждений и сбоев.

| Параметр | По умолчанию | Допустимые значения | Описание |
| :--- | :--- | :--- | :--- |
| `DEST` | `~/Downloads/Media` | Путь | Каталог для сохранения загруженных медиафайлов. |
| `CONCURRENT_FRAGMENTS` | `8` | Число (`1`–`16`) | Количество одновременных потоков скачивания фрагментов. |
| `DEFAULT_CONTAINER` | `mp4` | `mp4`, `mkv`, `webm` | Целевой контейнер для сборки видео и аудио. |
| `APPLE_COMPAT_MODE` | `true` | `true`, `false` | Принудительное приведение к совместимым с Apple кодекам (H.264/AAC). |
| `EMBED_METADATA` | `true` | `true`, `false` | Вшивание метаданных (название, автор, дата публикации). |
| `EMBED_THUMBNAIL` | `true` | `true`, `false` | Интеграция постера в качестве обложки трека или видеофайла. |
| `COOKIE_BROWSER` | `none` | `none`, `safari`, `chrome`, `firefox` | Чтение сессионных куков браузера для доступа к закрытым материалам. |
| `SOUND_ENABLED` | `true` | `true`, `false` | Воспроизведение звукового сигнала macOS по окончании загрузки. |
