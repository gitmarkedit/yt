## Установка

Одна команда для чистого Mac (Apple Silicon M1/M2/M3/M4 и Intel). Не требует предварительной установки полного пакета Xcode (12+ ГБ):

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/gitmarkedit/yt/main/install.sh)"
```

Установщик выполняет аудит имеющихся компонентов, предлагает установку через Homebrew либо быстро разворачивает автономные бинарники в папку проекта, прописывает системную команду `yt` и сразу запускает интерфейс.

<details>
<summary><b>Дополнительные варианты установки</b></summary>

### Автономный архив (без Homebrew)
```bash
mkdir -p ~/yt && curl -fsSL https://github.com/gitmarkedit/yt/archive/refs/heads/main.tar.gz | tar -xz -C ~/yt --strip-components=1 && bash ~/yt/install.sh
```

### Клонирование репозитория
```bash
git clone https://github.com/gitmarkedit/yt.git ~/yt && cd ~/yt && bash install.sh
```

#### Флаги установщика `install.sh`:
- `--brew` — использовать Homebrew (установит brew при его отсутствии).
- `--standalone` — автономная установка бинарников без root-прав.
- `--no-launch` — не запускать интерфейс автоматически после завершения.
</details>

## Системные особенности macOS

- **VideoToolbox Hardware Acceleration** — аппаратное кодирование и мультиплексирование на медиа-ядрах Apple Silicon (M1–M4). Минимальная нагрузка на CPU и отсутствие нагрева при сборке тяжелых 4K/8K потоков.
- **FastStart (`-movflags +faststart`)** — размещение метаданных `moov atom` в начале MP4-контейнера. Файлы любого размера открываются мгновенно по нажатию **Space** (QuickLook) в Finder без ожидания полной буферизации.
- **Apple Compatibility Mode** — строгая упаковка в нативные для экосистемы Apple кодеки H.264/HEVC и AAC. Файлы гарантированно воспроизводятся в QuickTime Player, приложении «Фото», на iPhone/iPad и транслируются через AirPlay без черного экрана.
- **Многопоточный конвейер (`-N 8`)** — параллельная загрузка медиа-фрагментов в 8 потоков на Apple Silicon для максимальной утилизации пропускной способности сети.
- **Интеграция с буфером обмена (`pbpaste`)** — при копировании ссылки в Safari или Chrome (`⌘C`), интерфейс мгновенно предлагает её при нажатии `Enter`.
- **Нативные уведомления и звук** — системный сигнал (*Glass*) и всплывающее уведомление Notification Center по завершении работы.
- **JavaScript Runtimes** — автоматическое подключение Node.js или Deno для обхода player challenge.

## Режимы работы

| Режим | Описание | Применение |
| :--- | :--- | :--- |
| **Максимальное качество** | Склейка лучшего видеопотока (до 4K/8K 60fps) и аудиопотока без потерь | Фильмы, клипы, архивация |
| **Сразу MP3** | Экстракция звука в MP3 (320 kbps) со вшиванием обложки и ID3-тегов | Подкасты, лекции, музыка |
| **Минимальный вес** | Сжатый поток для экономии дискового пространства и мобильного трафика | Быстрый просмотр, аудиокниги |
| **Выбор разрешения** | Выбор вручную: 2160p (4K), 1440p (2K), 1080p, 720p, 480p, 360p | Подгонка под экраны устройств |
| **Аудиоформаты** | Экспорт в Apple M4A (AAC), FLAC (Lossless), WAV, OPUS | Аудиофилы, монтаж звука |
| **Тайм-слайс** | Загрузка конкретного отрезка по времени (например, `01:15-04:20`) | Цитаты, вырезки, фрагменты |
| **Плейлисты** | Загрузка всей подборки или диапазона номеров (`1-10`) | Курсы, плейлисты, альбомы |
| **Анализ форматов** | Просмотр таблицы потоков (`yt-dlp -F`) и выбор по ID вручную | Тонкая настройка битрейта |
| **Субтитры** | Загрузка внешних или вшитых субтитров (RU, EN или все доступные) | Переводы, языковая практика |
| **Обложка** | Извлечение постера в максимальном разрешении | Графика, оформление |

## Параметры конфигурации

Файл конфигурации расположен по пути `~/.config/yt-downloader/config.env` и создается автоматически.

| Параметр | По умолчанию | Допустимые значения | Описание |
| :--- | :--- | :--- | :--- |
| `DEST` | `~/Downloads/Media` | Абсолютный путь | Каталог для сохранения загруженных медиафайлов. |
| `CONCURRENT_FRAGMENTS` | `8` | Целое число (`1`–`16`) | Количество одновременных потоков скачивания фрагментов. |
| `DEFAULT_CONTAINER` | `mp4` | `mp4`, `mkv`, `webm` | Целевой контейнер для сборки видео и аудио. |
| `APPLE_COMPAT_MODE` | `true` | `true`, `false` | Принудительное приведение к совместимым с Apple кодекам (H.264/AAC). |
| `EMBED_METADATA` | `true` | `true`, `false` | Вшивание метаданных (название, автор, дата публикации). |
| `EMBED_THUMBNAIL` | `true` | `true`, `false` | Интеграция постера в качестве обложки трека или видеофайла. |
| `COOKIE_BROWSER` | `none` | `none`, `safari`, `chrome`, `firefox` | Чтение сессионных куков браузера для доступа к закрытым материалам. |
| `SOUND_ENABLED` | `true` | `true`, `false` | Воспроизведение звукового сигнала macOS по окончании загрузки. |

## Диагностика системы (`yt --doctor`)

Комплексный аудит окружения и самоотладка:

```bash
yt --doctor
```

Проверяемые узлы:
1. **Интерпретатор Bash** — совместимость с нативным `/bin/bash` 3.2+ macOS.
2. **Аппаратная платформа** — модель CPU и архитектура (Apple Silicon M-серии / Intel).
3. **Загрузчик yt-dlp** — путь, версия и права на исполнение.
4. **Медиа-движок FFmpeg** — проверка бинарника и аппаратных энкодеров `videotoolbox`.
5. **Интерфейс fzf** — статус интерактивного TUI-селектора.
6. **Системные интерфейсы macOS** — `pbpaste`, `osascript`, `afplay`, JS-движок (Node.js/Deno).
7. **Дисковая подсистема** — доступность прав на запись и свободное место в `DEST`.
8. **Файл конфигурации** — валидность синтаксиса `config.env`.
